# Spectrum Axes: Territory, Borders & Security

**Summary**: Detailed comparison of 5 axes from [[confederation-spectrum-framework]] — border permeability, external-frontier control, Jerusalem governance, settler/settlement status, and security integration — across the five reference configurations.

**Sources**: See [[confederation-spectrum-framework]] for the full sourcing note and reliability caveats applying to all five configuration columns.

**Last updated**: 2026-09-03

---

## Border Permeability (Israel-Palestine)

| Configuration | Description |
|---|---|
| **1. Status Quo** | Fragmented: Area A/B under partial PA control, Area C (60% of West Bank) under full Israeli control; Gaza sealed/blockaded; extensive checkpoint network |
| **2. Full Annexation** | No internal border — full Israeli sovereignty over annexed territory; Gaza's status typically left unaddressed by annexation proposals, which usually target the West Bank (mainly Area C) specifically |
| **3. State of All Its Citizens** | No internal border — single state, single citizenship, unrestricted internal movement |
| **4. A Land for All** | Open border with freedom of movement, but each state retains right to deny entry/conduct checks (per primary platform, [[a-land-for-all-primary-platform]]) |
| **5. Two States for Two Peoples** | Closed, negotiated border with formal crossings between two fully separate sovereign states; more restrictive than ALFA's open-border model |

## External-Frontier Control

| Configuration | Description |
|---|---|
| **1. Status Quo** | Israel controls all external frontiers (Jordan Valley, airspace, and — with Egyptian coordination — the Rafah crossing) |
| **2. Full Annexation** | Israel controls all external frontiers unilaterally and permanently |
| **3. State of All Its Citizens** | Single state controls its own frontiers as one sovereign entity |
| **4. A Land for All** | Each state controls its own external frontiers independently; not shared with third parties per the primary platform text found |
| **5. Two States for Two Peoples** | Palestinian state's sovereignty over its own frontiers is typically **limited** — most classic two-state proposals (incl. Clinton Parameters) envision international/Israeli security presence at Palestinian external crossings for a transition period |

## Jerusalem Governance

| Configuration | Description |
|---|---|
| **1. Status Quo** | Israel claims full sovereignty over a "unified" Jerusalem (since 1967 and the 1980 Basic Law); not internationally recognized; the Temple Mount/Haram al-Sharif operates under a distinct long-standing "status quo arrangement" (Jordanian Waqf religious authority, Israeli security control) — itself a fragile, separately-negotiated micro-regime worth noting as a dispute within the dispute |
| **2. Full Annexation** | Full, permanent, unilateral Israeli sovereignty entrenched with no shared arrangement of any kind |
| **3. State of All Its Citizens** | Single capital of the unified state; whether Palestinian residents retain any distinct communal/religious status within a purely civic framework is unresolved in sources reviewed — **needs verification** |
| **4. A Land for All** | Joint, **equal** Israeli-Palestinian municipal government, per the primary 2014 platform text (a genuine point of specificity — see the resolved discrepancy in [[a-land-for-all-primary-platform]]) |
| **5. Two States for Two Peoples** | Divided by neighborhood/sovereignty per most classic proposals (Clinton Parameters: Arab neighborhoods to Palestine, Jewish neighborhoods to Israel), with special, separately-negotiated arrangements for the Old City/Haram al-Sharif/Temple Mount — a physically partitioned model, distinct from ALFA's single joint municipality |

## Settler/Settlement Status

| Configuration | Description |
|---|---|
| **1. Status Quo** | ~500,000+ settlers live under Israeli civil law and IDF protection in the West Bank; Palestinians in the same territory live under Israeli military law — a much-cited core legal asymmetry |
| **2. Full Annexation** | Settlers become fully equal citizens under sovereign Israeli law, permanently; Palestinian residents' status remains the contested, unresolved question (see [[axes-citizenship-rights]]) |
| **3. State of All Its Citizens** | All residents — settlers and Palestinians alike — become equal citizens under one civic law; the settler/Palestinian distinction dissolves into individual citizenship |
| **4. A Land for All** | Settlers become **residents (not citizens) of Palestine** under Palestinian law, with local-authority voting rights only; settlement expansion explicitly frozen; gradual implementation to avoid demographic overwhelm |
| **5. Two States for Two Peoples** | Most settlers relocated into Israel proper via negotiated land swaps (Clinton Parameters envisioned incorporating ~80% of settlers this way); settlements outside the swap areas evacuated — a substantially more separative outcome for settlers than ALFA's "stay as residents" model |

## Security Integration

| Configuration | Description |
|---|---|
| **1. Status Quo** | Full IDF operational freedom throughout the West Bank in practice (including Area A); nominal Oslo-era Israeli-PA security coordination, frequently suspended/limited; Gaza under blockade with periodic military operations |
| **2. Full Annexation** | Full, permanent Israeli security control over annexed territory |
| **3. State of All Its Citizens** | Single unified national army/security force for the whole state, as in any unitary state |
| **4. A Land for All** | Separate security forces per state, but close cooperation on intelligence/policing; explicit demilitarization commitments; **no Israeli military presence** inside the Palestinian state (see [[a-land-for-all-primary-platform]]) |
| **5. Two States for Two Peoples** | **Demilitarized Palestinian state** (explicit in the Clinton Parameters and most classic proposals) with international force presence (e.g., in the Jordan Valley) during a transition period, plus Israeli early-warning stations — Palestinian sovereignty is *security-limited* in a way ALFA's "no Israeli military presence, but full Palestinian security force" model is not |

## Key Cross-Axis Observation

**Classic "Two States for Two Peoples" is more separative than commonly assumed relative to A Land for All** — border closure, external-frontier control, security limitation, and settlement evacuation are all **more separative** in the classic model than in ALFA's confederative approach, even though both are conventionally grouped together as "two-state" solutions. This is a genuinely useful distinction the spectrum framework surfaces that a binary "two-state vs. one-state" framing would obscure — the two models look similar on the map (two sovereign states) but differ substantially on nearly every axis on this page.
