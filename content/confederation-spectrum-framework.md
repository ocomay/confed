# Confederation as a Spectrum — Project Framework & Foundational Assumptions

**Summary**: The methodological framework underlying this research topic — confederation is treated not as a single fixed proposal but as a region within a multidimensional space, where each dimension ("axis") corresponds to one of the conflict's core points of dispute. This page states the framework's foundational assumptions and carries a compact dashboard; full axis-by-axis detail lives in 4 linked sub-pages.

**Sources**: User-defined project methodology (2026-09-03), building on the disputes already catalogued in [[final-status-core-disputes]].

**Last updated**: 2026-09-03

---

## The Foundational Assumptions (as stated)

1. **Confederation is not a single, fixed thing — it is a spectrum.** There is no one "confederation model"; there is a range of possible arrangements that could all reasonably be called confederative, differing in degree.

2. **This spectrum can be approximated as a multidimensional space, spanned by a number of axes.** Rather than a single left-to-right scale ("more" or "less" confederative), the space has multiple independent dimensions, each capturing a different aspect of how integrated or separated the two political entities are.

3. **The axes are not fully independent — there are correlations and dependencies between them — but in aggregate, a sufficiently large set of axes gives a good picture of the state of confederation.** Full independence between dimensions isn't assumed or required; the framework is useful even with realistic cross-axis coupling, as long as enough axes are specified.

4. **The axes are themselves the points of dispute/friction between the two sides.** This is the key structural claim: the dimensions of the space are not abstract political-science categories invented for this framework — they are precisely the concrete, contested issues already fought over between Israelis and Palestinians (see [[final-status-core-disputes]]). Each dispute *is* an axis; resolving or not-resolving it, and to what degree, is what moves a given arrangement along that axis.

5. **The current status quo is itself a point on the confederation spectrum (implicitly).** The present situation — occupation, closure, separation, asymmetric control — is not something *outside* or *prior to* the space of confederative arrangements; it is one specific point (or region) *within* that same space, typically at or near the "minimal integration" extreme on most axes. This matters because it means "the status quo" and "full confederation" and "one unified state" are not different *kinds* of things requiring different frameworks — they are different *locations* in the same space, describable with the same set of axes.

6. **A gradual, incremental transition along the spectrum is possible, and could itself serve as a trust-building mechanism.** One of the hardest obstacles to implementing any solution to the conflict is deep mutual distrust between the parties. But if confederation is a spectrum (assumption 1) and the status quo is itself already a point on it (assumption 5), a step-by-step movement over time — from the status quo toward a desired final-status point — becomes conceivable, rather than requiring a single discrete leap to a fully-specified end state. Progressing incrementally, one step at a time, would allow trust to be built along the way, with advancement to each next intermediate point conditioned on both sides' satisfaction with the current one — rather than treating pre-existing trust as a precondition for starting at all.

## Why This Framework Matters

### It reframes "does confederation work?" as a badly-posed question
Given assumption 1, asking whether "confederation" succeeds or fails, or whether it is "popular" or "unpopular," is under-specified — different points in the space could have very different feasibility, popularity, and normative properties. A more precise version of the question specifies *which region* of the space is being evaluated. This retroactively explains a real problem already encountered in this wiki: [[a-land-for-all-primary-platform]] found that the organization's own platform description **moved over time** (2014 → 2026) toward vaguer, less specific language — which, in this framework's terms, is a shift from a **sharply-located point** in the space (2014's precise mechanisms) toward a **fuzzier region** (2026's "creative and fair solutions" language on Jerusalem, settlements, refugees). The apparent inconsistency isn't necessarily a contradiction — it may be the organization deliberately keeping its position under-specified on several axes.

### It explains why critiques from opposite directions can both be right
[[confederation-model-critique]] already documented that the Palestinian-rights critique (Chacar) and the realist/security critique (Konrad/RAND) — despite starting from opposite premises — **converge** on the same objection (the ~30x power/economic asymmetry). In this framework's terms: both critiques are really claims about **where on certain axes** (e.g., an "economic integration" axis, a "sovereignty symmetry" axis) A Land for All's specific proposal sits, and both independently observe that it sits at a point that **formalizes rather than closes the asymmetry gap** on those axes — even though one critique wants the point to move *further* toward integration/equality and the other thinks even the current point is *already too far* for either side's comfort.

### It clarifies what "the status quo" and "confederation" share
Per assumption 5, describing the status quo *using the same axes* as any confederation proposal is analytically useful precisely because it lets you see the status quo as an existing, specific configuration — e.g., a border axis near "hard closure," a citizenship axis near "zero mutual residency," a security axis near "unilateral Israeli control," a Jerusalem axis near "unilateral Israeli sovereignty, contested." This makes it possible to describe *any* proposal, including the status quo, "annexation," "one democratic state," "classic two-state partition," and every point along "confederation," using **one consistent set of axes** rather than treating each as a categorically different kind of arrangement needing its own framework.

### It offers a path around the mutual-distrust problem (assumption 6)
The wiki already documents deep, well-sourced mutual distrust as a central obstacle: RAND's study found "the data highlight the deep distrust and profound animosity of each side for the other" (Daniel Egel, lead author — see [[confederation-model-critique]] and [[israeli-palestinian-public-opinion-polling]]), and the confederation interview itself raised the question of where trust would come from at all (Hardal's response — see [[eretz-lekulam-confederation-interview]] — that trust-building cannot wait for pre-existing trust, but needs the right *conditions*). Assumption 6 gives that response a concrete mechanism *within this framework specifically*: because the space is continuous (assumption 2) and the status quo is a point within it (assumption 5), movement doesn't have to mean jumping straight to a fully-specified final-status point on every axis at once — it can mean advancing a few axes at a time, with each step's continuation conditioned on both sides finding the *previous* step tolerable. This reframes "we don't trust each other enough to do this" not as a blocking precondition, but as a reason to sequence and gate the movement itself. It also connects to the staged-implementation precedents already catalogued in [[comparative-conflict-resolutions]] (Oslo's own original phased design, the Dayton Agreement's implementation timeline, Northern Ireland's phased decommissioning) — though those precedents are flagged there as needing deeper verification before treating them as validating evidence for this specific mechanism.

**Open design question this assumption raises, not yet answered anywhere in the wiki**: what determines the *order* in which axes move, and what counts as "satisfaction" sufficient to unlock the next step? Neither is specified by assumption 6 itself — it establishes that gradual movement is conceivable and could build trust, not a sequencing algorithm. See the Open Methodological Questions section below.

## Candidate Axes (Derived from [[final-status-core-disputes]])

The disputes already catalogued in this wiki are natural candidates for axes, reframed as **continuous dimensions** rather than binary "resolved/unresolved" questions. The **14 axes are grouped into 4 themes**, each with its own detailed sub-page (full prose comparison across all five configurations, with quotes and citations). This page now carries only a compact dashboard for quick scanning, plus the cross-cutting insights — **the previous version of this page had one giant 14-row table that became unreadable; it has been split per user request (2026-09-03).**

**The five configurations compared** (full detail and sourcing caveats in each sub-page):
1. **Status quo** — the present arrangement (referencing the Oslo Accords' Areas A/B/C division and the 1997 Hebron Protocol's H1/H2 division where directly relevant)
2. **Full annexation** — per explicit Israeli right-wing positions (see [[israeli-right-wing-opposition]])
3. **"State of all its citizens"** (מדינת כל אזרחיה) — the single-state civic model associated with Azmi Bishara and the Balad party
4. **A Land for All's proposal** — per [[a-land-for-all-primary-platform]]
5. **"Two states for two peoples"** — the classic/mainstream two-state solution (Clinton Parameters-style)

Column 3 is sourced from a brief search-result characterization only — **needs deeper verification**. Column 4 remains the most rigorously sourced (primary platform text).

## Locating Existing Wiki Content on This Framework (summary insights — full detail in sub-pages)

- **Status quo and Full Annexation cluster together** on most axes (low citizenship symmetry, low self-determination symmetry, high Israeli unilateral control) — annexation is best read as an **intensification** of the status quo's existing asymmetries, not a departure from them, **except** that it removes even the nominal PA civil authority that Areas A/B currently preserve.
- **"State of All Its Citizens" and classic "Two States for Two Peoples" are the two most internally consistent, opposite-extreme configurations** — the former resolves every axis via civic unification, the latter via full separation. Both are more axis-by-axis *consistent* than A Land for All, which deliberately mixes high-integration axes (Jerusalem, security cooperation) with low-integration axes (citizenship).
- **A Land for All occupies a genuinely intermediate, mixed position** — this is the dashboard's most important finding: it is not simply "between" the status quo and full unification on a single scale, but combines specific high-integration choices (joint Jerusalem, no Israeli military presence, settler/refugee residency rights) with a specific, deliberate low-integration choice (fully separate citizenship law, "as they see fit"). This is only visible using the multidimensional framework (assumption 2) — a single left-right scale would misrepresent it as simply "moderate."
- **Classic "Two States for Two Peoples" is more separative than commonly assumed relative to ALFA** on several axes — border closure, external-frontier control, security limitation, and settlement evacuation are all **more separative** in the classic model than in ALFA's confederative approach, even though both are conventionally grouped together as "two-state" solutions. See [[axes-territory-borders-security]] for full detail.
- **Gaza governance and Palestinian political unity are weak/undertheorized across every column except the status quo** — none of the four alternative models has a well-sourced, specific answer for how Gaza's current internationally-administered status or the Fatah-Hamas split gets resolved. See [[axes-governance-representation]].
- **"No representation" is already the status quo for part of the population, not a hypothetical risk** — Area C Palestinians and Gaza residents currently have no functioning vote in whichever body actually governs them. Full annexation's core function is to make this **permanent and explicit**. Conversely, A Land for All's dual-citizenship/possible-dual-vote mechanic for Arab citizens of Israel has no parallel elsewhere. See [[axes-governance-representation]].
- **A Land for All is the least institutionally specific of the five configurations on both resource axes** (water, economic integration) — in contrast to its notably precise commitments on Jerusalem and citizenship. See [[axes-resources-economy]].

## Open Methodological Questions

- **How many axes are "sufficient" per assumption 3?** The framework proposes 14 candidates across 4 themes; it's not yet established whether this is close to sufficient, redundant, or missing major dimensions (e.g., no axis yet for religious/holy-site access specifically, distinct from general Jerusalem governance).
- **Are the axis endpoints well-defined, or do they need sub-scales?** E.g., "security integration" plausibly bundles several distinguishable things (joint intelligence-sharing vs. joint patrols vs. a unified command structure) that might deserve separate axes.
- **Should "current status quo" be treated as a single point, or does it already vary axis-by-axis in ways that need documenting separately** (e.g., status quo water allocation is a fairly hard, quantifiable ~80/20 split, while status quo "security integration" is more qualitatively described)?
- **How should this framework handle proposals this wiki hasn't yet ingested** (e.g., the specific 2022 Israeli-Palestinian confederation proposal noted but not yet profiled in [[a-land-for-all]]'s related-sources list)? Each would need its own axis-by-axis mapping to be comparable.
- **What sequencing and gating mechanism would assumption 6's incremental transition actually use?** Neither the order in which axes should move, nor what constitutes sufficient "satisfaction" to unlock the next step, is specified yet — this is a real gap, not just an unexplored detail, since a badly-sequenced transition could plausibly *increase* distrust (e.g., moving a highly visible, symbolically loaded axis like Jerusalem before lower-stakes axes have built any track record) rather than build it.

## How This Should Guide Future Wiki Work

Going forward, ingesting a new source about a specific proposal (confederation or otherwise) should, where possible, note **where that proposal sits on each relevant axis** — not just summarize it narratively. This makes proposals genuinely comparable to each other and to the status quo, rather than each being assessed only against its own stated goals. New axis-level detail should be added to the relevant thematic sub-page, with the dashboard here updated to match.
